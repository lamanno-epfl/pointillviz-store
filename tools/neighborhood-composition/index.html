Readme

Answers the question: How mixed is each cell’s neighbourhood, and which groups occur next to one another more or less often than expected?

For each cell i, the tool finds its k nearest neighbours and records how many belong to each group.

Map. Each cell is colored by the normalized Shannon entropy of its neighbourhood:

Mi=−∑jpijlog(pij)log(T)

Here, pij is the proportion of cell i’s labelled neighbours belonging to group j, and T is the number of groups present in the dataset. A score of 0 means that all labelled neighbours belong to the same group. Higher values indicate that several groups are represented more evenly.

Matrix. Both axes list all groups. Each square compares the observed number O(A,B) of A-to-B neighbour relations with the expected number E(A,B):

score(A,B)=log2(O(A,B)+1E(A,B)+1)

A score of 0 means that the observed and expected numbers match. Scores of +1 and −1 indicate approximately twice and half the expected number, respectively.

The expected number is calculated by multiplying the total number of valid neighbour positions around all A-cells (usually about n(A) × k) by the proportion of valid neighbour positions across all groups occupied by B-cells. Because the calculation counts neighbour positions rather than unique cells, the same cell may be counted multiple times, depending on its position and how many other cells include it among their k nearest neighbours.

Table. Each row summarizes one group. Cells scored is the number of its cells with a valid mixing score, while Mean mixing is their average Mi. Self log2 O/E is the group’s diagonal matrix value and indicates whether its cells cluster together or are more dispersed. Most enriched neighbour is the other group with the highest matrix score, and the accompanying log2 O/E column gives that score.

References

Shannon (1948) Bell Syst. Tech. J. 27:379-423; Pielou (1966) J. Theor. Biol. 13:131-144.

Parameters

ParameterTypeDefaultWhat it does
Neighbours (k)k int, 3–100 15 Sets how many nearest cells define each neighbourhood. Larger values measure mixing over a broader area and produce a smoother result.
Grouping columnfield categorical_field optional Selects the annotation used to define the groups. Defaults to the dataset’s cell-type column.
Minimum cells per categorymin_type_cells int, 0–5,000 25 Categories with fewer cells are not shown in the matrix or table, but are still included in each cell’s mixing score.
