Readme

Which cell types form one connected structure, and which are split into separate patches?

For each group in the selected annotation, two cells are connected when they are no more than a distance r apart. Connections can form chains: if cell A is connected to B and B to C, all three belong to the same patch. As r increases, smaller patches merge into larger structures.

Map. Each cell is colored by the log10 size of its connected same-group patch at a fixed linking distance. Brighter colors indicate larger patches, darker colors indicate smaller patches, and unpainted cells have no result.

Plot. The x-axis shows the linking distance r, normalized by the typical nearest-neighbor distance within each group. The y-axis shows the fraction of the group’s cells contained in its largest connected patch.

Pc(r)=cells in the largest patchall cells in group c

Each line represents one group. Curves rising further to the left indicate greater connectivity, while curves rising further to the right indicate greater fragmentation.

Table. The percolation threshold r* is the smallest distance at which the largest patch contains the selected fraction of the group, 50% by default. r*/NN expresses this threshold relative to the group’s own spacing. r*/null compares it with random groups of the same size: values below 1 indicate greater connectivity than expected, while values above 1 indicate greater fragmentation.

References

Stauffer, D. & Aharony, A. (1994). Introduction to Percolation Theory, 2nd ed. Taylor & Francis. Gower, J. C. & Ross, G. J. S. (1969). Minimum spanning trees and single linkage cluster analysis. Applied Statistics 18(1), 54-64.

Parameters

ParameterDefaultWhat it does
Grouping column field optionala categorical column Selects the annotation used to define the groups.
Minimum cells per category min_cells Default: 50105,000Range 10 to 5,000. Categories with fewer placed cells than this are not scored and appear unpainted (grey) on the map.
Giant-component fraction giant_frac Default: 0.50.10.9Range 0.1 to 0.9. Sets the fraction of a group that must belong to its largest connected patch to define the percolation threshold r*.
Null draws n_sims Default: 19049Range 0 to 49. Sets the number of random groups used for comparison. More draws provide a more precise comparison but increase runtime; 0 disables the null results and grey band.
Patch-map link radius link_scale Default: 30.520Range 0.5 to 20. Sets the distance used to define map patches. Cells are colored by patch size at that distance; the plot and r* are unchanged.
Maximum cells per category max_per_type Default: 40,0005,000200,000Range 5,000 to 200,000. Limits runtime by reproducibly subsampling larger categories. Subsampling may change the map and threshold results.
