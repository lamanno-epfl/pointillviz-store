Readme

Which tissue domains, or niches, does a section divide into, judged by what each cell and its neighbours express?

The tool runs BANKSY (Singhal, Chou, Lee et al., Nature Genetics 2024) with the authors’ own Python package, imported from PyPI as they ship it (pybanksy 1.3.5). It calls the package’s functions in the order of the authors’ notebooks, with their values, and holds no copy of their method:

  1. normalises the counts and keeps the most variable genes (normalize_total, filter_hvg);
  2. builds a spatial graph of each cell’s nearest neighbours (initialize_banksy);
  3. builds the BANKSY matrix: each cell’s expression, its neighbours’ weighted mean and, by default, the azimuthal Gabor filter (AGF), which responds where expression changes across a neighbourhood (generate_banksy_matrix);
  4. reduces it with PCA (pca_umap) and clusters the components with Leiden (run_Leiden_partition).

Called directly on the same counts, with no code of this tool, the authors’ functions give the same niches, cell for cell, on Xenium 5K sections of 135,231 and 235,803 cells.

Map. Every cell painted by its niche, numbered N1, N2, … from the largest.

Matrix. Each niche’s cell-type composition, or its marker genes if the dataset has no cell types.

Table. Each niche’s size, marker genes and main cell types, with a download of every cell’s niche.

Several sections. A cell’s neighbours always come from its own section. Z-score sets the rest. Per section, the default, each section gets its own z-scores and the matrices are joined before the PCA, as in the authors’ multi-sample notebook. Across all sections, the package runs once over every cell, with the sections set apart in space so that no neighbourhood crosses between them.

What the package does as shipped. The tool leaves these as they are:

  • The AGF is not centred: generate_banksy_matrix passes its variance_balance argument (False) into the center slot of create_nbr_matrix. Results can therefore differ from the authors’ R package.
  • Ranked weights fail with the AGF, so the tool refuses that combination with a sentence.
  • With scaled Gaussian or reciprocal weights, cells on the same spot make the package lose the whole neighbourhood block without a word. The tool refuses, and names the uniform weights.
  • The package’s other clustering, mclust, needs R and rpy2, and is not offered.

Cost. 135,231 cells take about 6 minutes and 21 GB at 2,000 variable genes, and a selection of 20,000 cells about 30 s. If the memory is not there, the tool says so before it starts, and which control to lower.

pybanksy is under the GPL-3.0 licence, and so is this tool.

References

Singhal V, Chou N, Lee J, et al. BANKSY unifies cell typing and tissue domain segmentation for scalable spatial omics data analysis. Nat Genet 56, 431-441 (2024).

Parameters

ParameterDefaultWhat it does
Neighbourhood weight (lambda) lambda_param Default: 0.801Range 0 to 1. How much a cell’s neighbourhood counts against its own expression (pybanksy’s lambda). The authors use 0.8 for tissue domains and 0.2 for spatially informed cell types; 0 ignores space.
Spatial neighbours (k_geom) k_geom Default: 15530Range 5 to 30. How many nearest cells make a neighbourhood. The authors’ default is 15, for single cells.
AGF order (max_m) max_m Default: 101Range 0 to 1. 1 adds BANKSY’s azimuthal Gabor filter, over twice the neighbours: it responds where expression changes across a neighbourhood, as at a border. It is the authors’ recommended default. 0 uses the neighbourhood’s mean alone, and a third less memory.
Neighbour weights nbr_weight_decay Default: Scaled Gaussian (the authors’ default) How a neighbour’s weight falls with its distance.

Or: Reciprocal, Ranked (AGF order 0 only), Uniform
Z-score zscore_by Default: Per section (the authors’ multi-sample way) Sets over which cells each gene is z-scored when a run holds several sections. It changes nothing on one section. Per section evens out differences in a gene’s overall level between sections, which suits replicates of one tissue. Across all sections keeps them, which suits sections of different tissues.

Or: Across all sections
Principal components (pca_dims) pca_dims Default: 20550Range 5 to 50. How many components of the BANKSY matrix the clustering sees. The authors’ default is 20.
Leiden resolution resolution Default: 0.70.053Range 0.05 to 3. Higher values give more, smaller niches; lower values give fewer, larger ones. 0.7 is the authors’ default. Not used when Number of niches is set.
Number of niches (max_labels) max_labels Default: 0030Range 0 to 30. 0 goes by the resolution. Any other number has pybanksy search for a resolution that gives that many niches, up to 25 tries of Leiden, so it takes longer and may stop short.
Expression neighbours (num_nn) num_nn Default: 5010100Range 10 to 100. How many neighbours each cell has in the graph Leiden partitions, in the space of the principal components. The authors use 50.
Variable genes (n_top_genes) n_top_genes Default: 2,000505,000Range 50 to 5,000. How many of the most variable genes to use. The authors use 2000. Time and memory grow in proportion.
Label refinement (iterations) refine_iterations Default: 005Range 0 to 5. How many times a cell takes the label of most of its 6 nearest cells. 0 is off. The authors offer it for domain segmentation, and warn against excess: it wears out fine domains.
