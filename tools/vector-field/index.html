Readme

In which direction does a selected quantity increase across the tissue, and how steeply?

The tool converts the selected quantity into a smoothed spatial field. Its gradient reveals the direction and strength of local changes across the tissue. Each cell j with a valid measurement receives a value aj. This is either the selected gene expression, a continuous measurement, or—for a selected population—1 for cells belonging to that population and 0 for other labelled cells.

At regularly spaced positions x across the tissue, the tool calculates a Gaussian-weighted local mean:

A(x)=∑jwj(x)aj,C(x)=∑jwj(x),F(x)=A(x)C(x)

The weight wj(x) decreases with the distance between cell j and position x, so nearby cells contribute more strongly to F(x) than distant cells. For a selected population, F(x) represents its smoothed local proportion.

From the spatial variation of this field, the tool calculates its gradient and magnitude:

∇F(x)=(∂F∂x,∂F∂y),g(x)=‖∇F(x)‖=(∂F∂x)2+(∂F∂y)2

Map. Cells are colored by the smoothed local value F(x): dark colors indicate lower values and yellow indicates higher values. The arrows show the gradient ∇F(x): their direction indicates the steepest increase, while their length represents the strength g(x) of the spatial change. For display, this strength is scaled nonlinearly as t(x)=min(g(x)/g95,1), where g95 is the 95th percentile of the displayed gradient magnitudes. Arrow color also represents F(x), not gradient magnitude.

Plot. To distinguish strong gradients from uncertain estimates, the tool calculates the effective cell count N(eff), the local variance τˆ2, and the standard error:

Neff(x)=(∑jwj(x))2∑jwj(x)2,τˆ2(x)=∑jwj(x)(a′j)2C(x)−(F(x)−a¯)2,SE(x)=τˆ(x)σp2Neff(x)

Here, a′j=aj−a¯ is the centered cell value, and σp is the spatial width of the Gaussian filter. A small effective cell count or high local variation increases the standard error. The x-axis shows a threshold t, while the y-axis shows the proportion of the M measurable positions whose standardized gradient magnitude z(x) reaches that threshold:

z(x)=g(x)SE(x),Sobserved(t)=1M∑x∈M1[z(x)≥t],Srandom(t)=e−t2/2

The solid curve shows the observed proportion. The dashed curve shows the frequency of standardized two-dimensional gradients expected from the Rayleigh distribution under random cell values. If the observed curve lies clearly above it, strong spatial gradients occur more often than expected by chance. The line at z=3 marks the default threshold below which arrows are hidden when filtering is enabled.

Parameters

ParameterDefaultWhat it does
Differentiate source Default: One level of a categorical column Selects whether the field represents the local proportion of a population, a continuous measurement, or gene expression.

Or: A gene, A continuous column
Categorical column field optionala categorical column Selects the categorical annotation used to define the populations. Used only when Differentiate is set to category. Defaults to the dataset’s cell-type column.
Level level optionalone of its categories Selects the population from the chosen categorical column whose local proportion is analyzed.
Continuous column column optionala continuous column Selects the continuous measurement to analyze. Used only when Differentiate is set to continuous.
Gene gene optionala gene Selects the gene whose normalized expression is analyzed. Used only when Differentiate is set to gene. Values are normalized to a total of 10,000 counts per cell.
Smoothing (σ, grid cells) sigma Default: 1.20.63Range 0.6 to 3. Sets the width of the Gaussian smoothing in grid cells. Larger values produce smoother fields with broader, weaker gradients.
Grid detail detail Default: 10.52.5Range 0.5 to 2.5. Sets the spatial resolution of the calculation. Higher values capture finer but noisier spatial changes.
Arrows arrows Default: 2,00020020,000Range 200 to 20,000. Sets the approximate number of arrows displayed. This changes the display density, not the calculated field.
Hide arrows that are not significant gate Default: onon or off Shows only positions with z ≥ 3 and at least 30 effective cells. Turning it off also displays gradients that may reflect noise.

  3. environmentpass

    pixi.lock matches pixi.toml, which declares python, numpy, scipy for linux-64, osx-64, osx-arm64, win-64; environments: default.

  4. entrypass

    tool.py imported in 0.00 s and defines run(ds, params).

  5. imports advisorypass

    2 source files, using __future__, numpy, pointillviz_tool, vfield_core; no network, subprocess, filesystem-write, dynamic-exec or environment use found.

  6. fixturepass

    ran on the 600-cell fixture in 0.01 s, returning summary, cells, vectors, series and 1 log line.

  7. resultpass

    returned the declared outputs: summary, cells, vectors, series.

  8. edgepass

    ran at the minimum corner (arrows=200, detail=0.5, gate=False, sigma=0.6) in 0.01 s; at the maximum corner (arrows=20000, detail=2.5, sigma=3.0, source='continuous') it refused in words rather than crashing: Nothing could be measured. Of 122 grid sites inside the tissue, none were far enough from a tissue edge for the smoothing window to sit entirely on real data, so no gradient at all was computed for cont_cell_area. The grid is too coarse, or σ too large, for a region this size: lower the smoothing, raise the grid detail, or widen the selection. (code: no_measurable_sites).

  9. no_mutationpass

    the fixture dataset's 4 files are byte-identical after every run (plugin_cache/, where ds.knn caches, is excluded by design).

Passing the gates is a statement about the gates, not about whether the code is safe to run.
