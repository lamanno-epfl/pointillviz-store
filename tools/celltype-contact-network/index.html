Readme

Answers the question: Which cell types touch which, and which of those contacts are more common, or rarer, than the types’ abundance predicts?

The tool runs a Delaunay triangulation on each section’s cells, in 2D or 3D, and counts every edge as one contact between two neighbouring cells. Tallying each cell’s neighbours by type gives a count matrix C, whose rows are then normalised:

Wij=Cij∑kCik

Wij is the fraction of type i‘s contacts that are with type j. It is not symmetric, because i → j and j → i are divided by different totals. The enrichment corrects for abundance, where pj is the fraction of all cells that are type j:

Eij=log2Wij+10−4pj+10−4

E > 0 means i touches j more than j‘s abundance predicts, and E < 0 less. With several sections, W is computed per section and each row is averaged across them, weighted by how many cells of type i each has.

Network. One node per cell type, its area growing with its number of cells. Its place comes from a layout of the whole dataset, so nodes stay put between sections. An arrow i → j appears where Wij reaches the cutoff, with its width growing as √W and its colour showing E, from blue (depleted) to red (enriched). The ring around a node is its self-contact: the further the ring stands from the node, the larger Wii.

Matrix. The same W and E with no cutoff. Colour shows E, the numbers are W in percent, and grey means no contact. Types with similar contacts sit together.

Table and downloads. Every contact between the types shown, the two figures as SVG, and the numbers for all types as CSV.

Delaunay edges are geometric neighbours, not measured contact, and E has no p-value, so read it together with the contact count C in the table. Cells across a gap are joined unless Longest contact is set.

Parameters

ParameterTypeDefaultWhat it does
Cell-type columnfield categorical_field optional Selects the annotation whose groups are the network’s nodes. Cell types, unless the dataset has none or you choose another column.
Longest contact (microns)max_distance float, 0–500 0 Drops contacts longer than this, so that cells across a gap do not count as touching. 0 keeps every contact. In the dataset’s own coordinates when it records no physical size.
Arrow cutoff (%)cutoff float, 0.5–50 4 Draws an arrow from one type to another only when at least this share of the first type’s contacts are with the second. The matrix has no cutoff.
Cell types shownmax_types int, 5–60 30 Shows only this many of the most abundant types, in the network and in the matrix. The others still count in every share, and the download holds them all.
