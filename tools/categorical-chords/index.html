Readme

Which categorical groups occur together more or less often than expected?

The tool compares categorical annotations such as cell types, clusters, or spatial niches. It offers two analysis modes:

  • Spatial contacts counts pairs of cells from the same section that lie within the selected radius.
  • Annotation relationships compares two categorical annotations assigned to the same cells, without using spatial coordinates.

For each pair of groups A and B, the tool compares the observed count O(A,B) with the expected count E(A,B):

score(A,B)=log2(O(A,B)+1E(A,B)+1)

The expectation is calculated from the group frequencies within each section. In annotation mode, E(A,B)=n(A)n(B)/N. In spatial-contact mode, it represents the number of A-to-B pairs expected if the group labels were randomly redistributed over the observed cell positions. A score of 0 indicates agreement with the expectation; positive values indicate enrichment and negative values depletion.

Chord. Each sector represents one group. Ribbon width shows the observed number of cells or spatial pairs connecting two groups, while ribbon color shows their log2(O/E) score: orange indicates enrichment and blue depletion. The display limits affect only the chord diagram, which shows the most abundant groups and best-supported relationships.

Matrix. Both axes list the selected groups, and each square shows the corresponding log2(O/E) score. The matrix retains all group combinations, including those omitted from the chord diagram.

Table. Each row represents one group pair. Count gives the observed number of cells or spatial pairs, Expected gives the expected count, and log2 O/E shows the enrichment or depletion.

ParameterDefaultWhat it does
Grouping annotation field requireda categorical column Selects the categorical annotation used for the groups. In annotation mode, this is the first of the two annotations.
Relationship mode Default: Spatial contacts Selects whether to analyze spatial contacts between different cells or relationships between two annotations on the same cells.

Or: Annotation relationships
Second annotation other_field optionala categorical column Selects the second annotation compared on the same cells.
Contact radius radius Default: 6011,000Range 1 to 1,000. Sets the maximum distance between two cells for them to count as a spatial contact, in dataset coordinate units.
Include within-group contacts self_links Default: offon or off Includes spatial contacts between cells belonging to the same group.
Minimum ribbon support min_count Default: 111,000Range 1 to 1,000. Shows a ribbon only when the relationship contains at least this many observed cells or spatial pairs.
Maximum sectors max_nodes Default: 20460Range 4 to 60. Limits how many groups appear around the chord diagram to the most abundant ones.
Maximum ribbons max_links Default: 801500Range 1 to 500. Sets the maximum number of relationships shown, keeping those with the highest observed counts.
