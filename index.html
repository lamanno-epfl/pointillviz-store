  • BANKSY niches

    Which niches the tissue divides into, judged by what each cell and its neighbours express.

  • Beeswarm Plot

    How marker genes are expressed across cell types or niches, one swarm of cells per group.

  • Categorical Chords

    Explore spatial contacts or shared membership between categorical annotations with count-weighted ribbons and enrichment colors.

  • Cell-type contact network

    Which cell types touch which, from a Delaunay triangulation of the cells, as a network and a matrix corrected for abundance.

  • Ridge Map

    How a gene, or the density of cells, rises and falls across a section, drawn as a relief of ridges.

  • Seurat niches

    Which niches the tissue divides into, judged by the cell types around each cell.

  • Smoothie

    Which genes share a spatial pattern across the tissue, grouped into modules.

  • Tissue Permeability

    Which cells one cell type seals off from the rest of the tissue.

  • Vector Field

    Which way a quantity increases across the tissue, as arrows over the section. Gene, cell type or any annotation column — with every arrow that could be noise removed.

  • Cell-Type Co-occurrence

    Which cell types are found near each other more often than expected by chance.

  • Cell-Type Percolation

    Whether a cell type is one connected mass or many islands.

  • Conditional Contact Odds

    How much one extra neighbour of type B changes the odds a cell is type A, holding every other type’s neighbour count fixed.

  • Expression Hotspots (Getis-Ord Gi*)

    Where one gene forms clusters of high or low expression.

  • Interface Coherence

    Whether two cell types meet along one front or in specks.

  • Local Cell Density

    How crowded the tissue is around every cell.

  • Neighborhood Composition & Mixing

    How mixed each cell’s neighbourhood is, and who sits next to whom.

  • Ripley’s Cross-L Function

    At what distance cell type B accumulates around cell type A.

Build & publish a tool

A tool is arbitrary code, and it runs with your privileges. Read the safety note

A tool is arbitrary code. An installed tool runs on your computer with the privileges of whoever started PointillViz, like any script you download. The gates report what a tool reaches for; they cannot stop it, and passing them says nothing about whether the code is safe. Each tool’s page links to its source in the public registry: read it before you install.
